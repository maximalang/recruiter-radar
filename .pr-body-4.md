## Summary
Surface MultiSourceLeadGenerator and LeadScoringService through hardened API routes:

- `POST /api/leads/generate` — generates leads from multiple sources, scoped to the authenticated owner.
- `POST /api/leads/score` — generates and scores leads against an `AgencyProfile`.

Both routes are guarded by the signed session cookie, validate input strictly, load owner-scoped digest items, and return sanitized errors that do not leak internal exception messages.

## Hardening details
- `readOwnerSession()` from `@/lib/session` gates both POST handlers; missing/invalid session returns 401.
- `generate`: validates `industries` is a non-empty string array; `regions`, `sources`, `maxResults` clamped.
- `score`: validates full `AgencyProfile` shape (industries non-empty, locations array, optional roles/companySizes/exclusions/remoteFriendly typed).
- Digest items are loaded server-side via `getHhDigestItems({ clientProfileId })`, owner-scoped via session.
- Errors are logged server-side as structured JSON with a `requestId`; the response carries a generic message and the same `requestId` for correlation — no `error.message` leak to the client.
- `runtime = 'nodejs'`, `dynamic = 'force-dynamic'`.
