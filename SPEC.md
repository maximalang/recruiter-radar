## 4. Технический стек
- **Frontend:** Next.js 14+ (React 18+)
- **Language:** TypeScript (strict mode)
- **Database:** PostgreSQL (через packages/db)
- **Сборка:** n8n для оркестрации
- **Развертывание:** Docker + Compose

## 5. Структура проекта
```
├── apps/web/                    # Веб-приложение Next.js
│   ├── app/                    # App Router
│   │   ├── api/                # API маршруты
│   │   ├── dashboard/          # Панель управления
│   │   ├── onboarding/         # Onboarding flow
│   │   └── ui/                 # UI компоненты
│   └── lib/                    # Библиотеки и утилиты
├── packages/db/                 # Бэкенд логика и источники данных
└── n8n/                       # Оркестрация
```

## 6. Стиль кода
### 6.1 Naming Convention
- **Функции и переменные:** camelCase (`getUserById`)
- **Интерфейсы и типы:** PascalCase (`UserId`)
- **Файлы:** kebab-case (`user-service.ts`)
- **Компоненты:** PascalCase для компонентов, camelCase для hooks

### 6.2 Import Style
- Использование абсолютных импортов через `@/`
- Группировка импортов: встроенные → внешние → внутренние
- Отсутствие неиспользуемых импортов

### 6.3 TypeScript Configuration
```json
{
  "compilerOptions": {
    "strict": true,
    "noEmit": true,
    "skipLibCheck": false
  }
}
```

## 9. Текущие проблемы

### 9.1 Критические TypeScript-ошибки (74 ошибки)
- `lib/case-conversion-middleware.ts` - ошибки приведения типов
- `lib/db.ts` - отсутствует тип PgPool
- `lib/digest.ts` - undefined properties при вычислении
- `lib/hooks.ts` - неэкспортированные типы из app-context
- `lib/publicProduct.ts` - неверные свойства объектов HH

### 9.2 Проблемы с тестированием
- Отсутствуют unit и интеграционные тесты
- Нет покрытия тестами критических функций

### 9.3 Дублирование кода
- Дублирующиеся утилиты в `validation-schemas.ts`

### 9.4 UX проблемы

- Нет адаптивности для мобильных устройств
- Минимальная доступность (accessibility)
