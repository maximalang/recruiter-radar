# Чек-лист для юридической проверки (counsel review)

Только решения, которые требуют квалифицированной правовой оценки.
Инженерная реализация консервативна и не должна меняться до ответов.

Контекст: продавец/оператор — самозанятый (НПД), сервис — информационно-аналитический
доступ для рекрутинговых агентств (B2B-first, возможна покупка физлицом), инфраструктура
в РФ, оплата через Robokassa, чеки НПД, доставка Telegram/VK/webhook/push/email.

## Что уже сделано без юриста (не требует повторной проверки)

- Разделение документов, отдельное согласие ПДн, отдельные checkbox'ы.
- Opt-in аналитика, симметричный отказ, отзыв, TTL ~14 месяцев, версия модели согласия.
- Отсутствие автопродления и скрытых списаний; серверное подтверждение платежа.
- Отсутствие рекламных рассылок и соответствующая фиксация в документах.
