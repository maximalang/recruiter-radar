# Data map — инвентаризация данных (по коду, август 2026)

Источники: миграции `packages/db/migrations/*`, `apps/web/lib/*`, страницы приложения.
Статус колонки «Механизм удаления»: ENFORCED (автоматика/скрипт) или MANUAL (ручной
процесс/отсутствует — см. retention-schedule.md).

## Аккаунт и аутентификация

| Данные | Цель | Основание | Источник | Хранение | Срок | Получатели | Трансгранично | Удаление |
|---|---|---|---|---|---|---|---|---|
| E-mail | регистрация, вход по одноразовой ссылке, статус заказа, чек | договор / pre-contract | пользователь | PostgreSQL (RF) | до удаления аккаунта + retention | почтовый провайдер (Яндекс.Облако Postbox) | нет | ENFORCED: purge script |
| auth_challenges (хэш e-mail, request_ip_hash, user_agent_hash) | одноразовые ссылки входа | договор, безопасность | система | PostgreSQL | технический срок challenge | нет | нет | MANUAL (cleanup script существует: `auth:cleanup-challenges`) |
| auth_sessions | сессия пользователя | договор | система | PostgreSQL | до отзыва/удаления | нет | нет | ENFORCED при удалении аккаунта; ротация |
| auth_security_events (типы событий, outcome, хэши subject/IP/UA) | безопасность, расследование инцидентов | законный интерес | система | PostgreSQL, append-only | 1 год заявлено в Политике; enforcement отсутствует | нет | нет | MANUAL → ACTION REQUIRED |
| `__Host-rr_session`, `__Host-rr_email_change`, `__Host-rr_workspace_invite` cookies | сессия/pending-действия | договор | система | cookie браузера | срок действия cookie | нет | нет | истечение/удаление |

## Не собирается

Полный номер карты, срок действия, CVC/CVV (вводятся только на странице Robokassa);
специальные категории ПДн; биометрия; данные несовершеннолетних (сервис 18+).
