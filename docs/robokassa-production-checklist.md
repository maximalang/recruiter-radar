## 2. Описание деятельности для анкеты

> Recruiter Radar — информационно-аналитический онлайн-сервис для рекрутинговых агентств. Сервис анализирует открытые hiring signals компаний и формирует подборки организаций, которым сейчас может быть актуально предложение услуг подбора. Пользователь получает доступ к личному кабинету, источникам и доказательствам сигнала, оценке уверенности, причинам актуальности и настраиваемым каналам доставки. Физическая доставка отсутствует.

Категория: программное обеспечение / информационно-аналитические услуги / доступ к онлайн-сервису.

Способ оказания услуги: цифровой доступ через сайт и отдельно подключённые пользователем каналы доставки.

## 5. Настройка тестового магазина

```env
PAYMENTS_PROVIDER=robokassa
ROBOKASSA_MODE=test
ROBOKASSA_MERCHANT_LOGIN=<merchant login>
ROBOKASSA_HASH_ALGORITHM=sha256
ROBOKASSA_TEST_PASSWORD_1=<test password 1>
ROBOKASSA_TEST_PASSWORD_2=<test password 2>
ROBOKASSA_RESULT_URL=https://recruiter-radar.ru/api/billing/webhook/robokassa
PAYMENTS_SITE_URL=https://recruiter-radar.ru
```

В кабинете Robokassa:

- Result URL: `https://recruiter-radar.ru/api/billing/webhook/robokassa`
- Метод Result URL: `POST`
- Алгоритм хеширования совпадает с `ROBOKASSA_HASH_ALGORITHM`.
- Success/Fail URL передаются для каждого заказа подписанными параметрами.
- Рекуррентные списания не подключаются.
- Для продавца на НПД подключаются «Робочеки СМЗ», а не 54-ФЗ-касса.

## 8. Live-настройка и возвраты

```env
ROBOKASSA_MODE=live
ROBOKASSA_PASSWORD_1=<live password 1>
ROBOKASSA_PASSWORD_2=<live password 2>
ROBOKASSA_PASSWORD_3=<live password 3>
ROBOKASSA_REFUND_JWT_ALGORITHM=HS256
```

- Password1 подписывает платёжную ссылку.
- Password2 проверяет ResultURL и используется для OpStateExt.
- Password3 подписывает JWT Refund API.
- Секреты не передаются браузеру и не хранятся в Git.
