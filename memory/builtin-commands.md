## Встроенные Slash Команды Claude

### Основные команды
- `/help` - Показать справку по использованию Claude
- `/clear` - Очистить контекст текущей сессии
- `/context` - Сформировать контекст перед началом работы
- `/compact` - Сжать длинную сессию с фокусированными инструкциями
- `/loop <interval> <command>` - Запустить команду с периодическим выполнением

### Команды для работы с проектами
- `/new` - Начать новую сессию для unrelated задач
- `/tasks` - Показать список задач для текущего проекта
- `/task <id>` - Получить детали конкретной задачи
- `/rename <topic>` - Переименовать текущую сессию

### Команды для анализа кода
- `/review` - Провести код-ревью изменений
- `/security` - Провести security review текущих изменений
- `/plan` - Создать план реализации задачи

### Команды для управления
- `/settings` - Показать текущие настройки Claude Code
- `/permissions` - Показать текущие разрешения для инструментов
- `/memory` - Показать содержимое memory системы
- `/config` - Быстрая настройка темы/модели

### Агенты и скиллы
- `/agents` - Показать список доступных агентов
- `/skills` - Показать список доступных скиллов
- `/skill <name>` - Использовать конкретный скилл

### Команды для Git
- `/git status` - Показать статус репозитория
- `/git diff` - Показать изменения
- `/git log` - Показать историю коммитов

### Команды для сборки и проверки
- `/check` - Запустить проверки кода (npm run check)
- `/build` - Запустить сборку проекта (npm run build)
- `/test` - Запустить тесты (npm run test)
