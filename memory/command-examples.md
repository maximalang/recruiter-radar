## Примеры использования Slash команд

### Начало работы
```bash
# Начать новую сессию
/new

# Сформировать контекст перед задачей
/context
```

### Работа с задачами
```bash
# Показать все задачи
/tasks

# Начать новую задачу
/task create

# Проверить детали задачи
/task 1
```

### Анализ кода
```bash
# Код-ревью изменений
/review

# Security review
/security

# Создать план реализации
/plan "Добавить функцию фильтрации компаний"
```

### Управление сессией
```bash
# Очистить контекст
/clear

# Сжать сессию
/compact

# Переименовать сессию
rename "Работа с API телеграм"
```

### Автоматические задачи
```bash
# Каждые 5 минут проверять статус
/loop 5m /git status

# Каждую минуту проверять сборку
/loop 1m /check
```

### Настройки Claude
```bash
# Показать текущие настройки
/settings

# Быстрая настройка
/config

# Показать разрешения
/permissions
```

### Работа с памятью
```bash
# Показать memory
/memory

# Добавить напоминание
/remember "Использовать TypeScript строго"
```

### Поиск и навигация
```bash
# Найти файлы
/find "*.ts"

# Найти символ
/symbol "getUserProfile"

# Показать дерево проекта
/tree
```
