### 💡 Полезные комбинации
```bash
# Начало работы с проектом
/context /task create "Новая фича"

# Проверка кода
/check /review /git status

# Анализ безопасности
/security /plan

# Сборка и тесты
/build /test
```

### 🎯 Ключевые сокращения
- `/h` = `/help`
- `/c` = `/clear`
- `/ctx` = `/context`
- `/rev` = `/review`
- `/sec` = `/security`
- `/git s` = `/git status`
- `/git d` = `/git diff`
- `/git l` = `/git log`
- `/npm c` = `/check`
- `/npm b` = `/build`
- `/npm t` = `/test`

### 📝 Best Practices
1. Используйте `/context` перед началом сложной задачи
2. Регулярно запускайте `/check` после изменений
3. Используйте `/review` перед коммитом
4. Храните часто используемые команды в memory с `/remember`
5. Используйте `/loop` для мониторинга прогресса
