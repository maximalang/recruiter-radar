План доработки проекта находится в [`docs/plan.md`](docs/plan.md) внутри рабочего дерева проекта. Это позволяет агентам видеть план при начале разработки без необходимости покидать проект.

Предыдущее местоположение: `C:\Users\max\.claude\plans\recruiter-radar\plan.md` (вне проекта)

**Why:** План должен быть доступен агентам в рамках контекста проекта для обеспечения согласованности разработки.

**How to apply:** При начале работы над задачами сначала читать SPEC.md, затем docs/plan.md для понимания контекста и фазы разработки.
