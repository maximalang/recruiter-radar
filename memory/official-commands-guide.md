## Официальное руководство по slash командам Claude (русский перевод)

### Управление сессиями / Session Management

#### `/new`
**Перевод:** `/новая`  
**Описание:** Начинает абсолютно новую сессию Claude. Полностью очищяет историю контекста и начинается заново. Используйте при переходе к совершенно другой задаче или проекту.

#### `/continue`
**Перевод:** `/продолжить`  
**Описание:** Продолжает самую последнюю сессию в текущей директории. Восстанавливает контекст и историю разговора.

#### `/clear`
**Перевод:** `/очистить`  
**Описание:** Очищает контекст текущей сессии, сохраняя при этом историю. Полезно при переключении между разными темами в рамках одной сессии.

#### `/compact`
**Перевод:** `/сжать`  
**Описание:** Сжимает длинную сессию с фокусированными инструкциями. Удаляет ненужный контекст, сохраняя только ключевую информацию.

#### `/rename`
**Перевод:** `/переименовать`  
**Описание:** Переименовывает текущую сессию для лучшей организации. Новое имя будет отображаться в интерфейсе Claude.

### Работа с проектами / Project Work

#### `/tasks`
**Перевод:** `/задачи`  
**Описание:** Показывает список всех задач в текущем проекте. Задачи отслеживаются в рамках сессии для управления рабочим процессом.

#### `/task create`
**Перевод:** `/задача создать`  
**Описание:** Создает новую задачу для отслеживания прогресса работы. Задачи помогают структурировать сложные проекты.

#### `/task <id>`
**Перевод:** `/задача <id>`  
**Описание:** Показывает детали конкретной задачи по ее ID. Включает статус, описание и прогресс.

### Анализ кода / Code Analysis

#### `/review`
**Перевод:** `/ревью`  
**Описание:** Проводит полное код-ревью текущих изменений. Анализирует качество кода, возможные улучшения и соответствие стандартам.

#### `/review-lite`
**Перевод:** `/ревью-лайт`  
**Описание:** Проводит быстрый код-ревью только для git изменений (без сборки). Оптимизирован для локальных изменений.

#### `/security`
**Перевод:** `/безопасность`  
**Описание:** Проводит углубленный security review текущих изменений. Проверяет на уязвимости, соответствие лучшим практикам безопасности.

#### `/ux`
**Перевод:** `/ux`  
**Описание:** Проводит UX/конверсионный review фокуса на пользовательском опыте и интерфейсах.

#### `/plan`
**Перевод:** `/план`  
**Описание:** Создает детальный архитектурный план реализации задачи. Включает пошаговое руководство с оценками.

### Git интеграция / Git Integration

#### `/git status`
**Перевод:** `/git статус`  
**Описание:** Показывает текущий статус Git репозитория: измененные файлы, staged изменения, untracked файлы.

#### `/git diff`
**Перевод:** `/git дифф`  
**Описание:** Показывает детальные различия между текущими изменениями и последним коммитом.

#### `/git log`
**Перевод:** `/git лог`  
**Описание:** Показывает историю коммитов в текущей ветке с опциональным фильтрованием.

#### `/git branch`
**Перевод:** `/git ветка`  
**Описание:** Показывает информацию о текущей Git ветке.

### Сборка и тестирование / Build & Testing

#### `/check`
**Перевод:** `/проверить`  
**Описание:** Запускает проверки кода проекта (например, `npm run check` для TypeScript проверок).

#### `/build`
**Перевод:** `/собрать`  
**Описание:** Запускает сборку проекта (например, `npm run build` для Next.js сборки).

#### `/test`
**Перевод:** `/тест`  
**Описание:** Запускает тесты проекта (например, `npm run test`).

#### `/validate`
**Перевод:** `/валидировать`  
**Описание:** Запускает валидацию конфигураций и схемы проекта.

### Системные команды / System Commands

#### `/help`
**Перевод:** `/помощь`  
**Описание:** Показывает полную справку по всем доступным командам и их использованию.

#### `/settings`
**Перевод:** `/настройки`  
**Описание:** Показывает текущие настройки Claude Code включая разрешения, переменные окружения и конфигурацию.

#### `/permissions`
**Перевод:** `/разрешения`  
**Описание:** Показывает текущие разрешения для инструментов (Bash, Read, Write и др.).

#### `/config`
**Перевод:** `/конфиг`  
**Описание:** Запускает быструю настройку основных параметров (тема, модель и др.).

### Memory система / Memory System

#### `/memory`
**Перевод:** `/память`  
**Описание:** Показывает содержимое auto-memory системы с организацией по категориям.

#### `/remember`
**Перевод:** `/запомнить`  
**Описание:** Сохраняет информацию в auto-memory систему для использования в будущих сессиях.

#### `/forget`
**Перевод:** `/забыть`  
**Описание:** Удаляет конкретную запись из auto-memory системы по ключу.

### Автоматизация / Automation

#### `/loop`
**Перевод:** `/цикл`  
**Описание:** Запускает команду с периодическим выполнением. Формат: `/loop <интервал> <команда>`.  
**Примеры:**
- `/loop 5m /git status` - проверять статус каждые 5 минут
- `/loop 1h /check` - проверять код каждый час

### Работа с агентами / Agent Work

#### `/agents`
**Перевод:** `/агенты`  
**Описание:** Показывает список всех доступных агентов (встроенных и кастомных).

#### `/agent <name>`
**Перевод:** `/агент <имя>`  
**Описание:** Активирует указанного агента для текущей сессии.

### Работа с плагинами / Plugin Management

#### `/plugins`
**Перевод:** `/плагины`  
**Описание:** Показывает список установленных плагинов и их статус.

#### `/plugin install`
**Перевод:** `/плагин установить`  
**Описание:** Устанавливает новый плагин из marketplace или по имени.

### Работа с MCP серверами / MCP Server Management

#### `/mcp`
**Перевод:** `/mcp`  
**Описание:** Показывает меню управления MCP серверами: запуск, остановка, настройка.

#### `/mcp list`
**Перевод:** `/mcp список`  
**Описание:** Показывает все настроенные MCP серверы и их статус.

### Утилиты / Utilities

#### `/find`
**Перевод:** `/найти`  
**Описание:** Ищет файлы в проекте по шаблону. Поддерживает glob-паттерны.  
**Пример:** `/find **/*.ts` - найти все TypeScript файлы

#### `/tree`
**Перевод:** `/дерево`  
**Описание:** Показывает дерево проекта в виде текстовой структуры.

#### `/version`
**Перевод:** `/версия`  
**Описание:** Показывает версию Claude Code и информацию о окружении.

#### `/debug`
**Перевод:** `/дебаг`  
**Описание:** Включает режим отладки с подробным логированием всех операций.

### Советы по использованию / Usage Tips

1. **Комбинации команд:** Многие команды можно комбинировать для эффективности  
   Пример: `/context /task create` - создать задачу с полным контекстом

2. **Контекстные команды:** Некоторые команды автоматически учитывают контекст проекта  
   Пример: `/review` проанализирует только изменения в рабочей директории

3. **Горячие клавиши:**  
   - `Ctrl+C` - прервать выполнение команды
   - `Ctrl+D` - выйти из Claude Code
   - `↑/↓` - навигация по истории команд

4. **Автодополнение:** Нажмите `Tab` для автодополнения имен команд
