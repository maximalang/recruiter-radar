## Быстрая справка - Slash команды Claude

### Начало работы
- `/help` - Справка
- `/new` - Новая сессия
- `/clear` - Очистить контекст

### Управление задачами
- `/tasks` - Список задач
- `/task create` - Создать задачу
- `/task <id>` - Детали задачи

### Работа с кодом
- `/review` - Код-ревью
- `/security` - Проверка безопасности
- `/plan` - План реализации

### Проверки проекта
- `/check` - npm run check
- `/build` - npm run build
- `/test` - npm run test

### Git команды
- `/git status` - Статус репозитория
- `/git diff` - Изменения
- `/git log` - История

### Memory система
- `/memory` - Показать память
- `/remember "текст"` - Сохранить в память

### Настройки
- `/settings` - Текущие настройки
- `/config` - Быстрая настройка
- `/permissions` - Разрешения

### Полезные комбинации
- `/context /task create` - Создать задачу с контекстом
- `/review /git status` - Ревью + статус
- `/plan /check` - План + проверки
