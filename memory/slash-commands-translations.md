## Системный перевод всех встроенных slash команд Claude

### Основные команды / Basic Commands
| Command | Русский перевод | Описание |
|---------|----------------|----------|
| `/help` | `/помощь` | Показать справку по использованию Claude |
| `/clear` | `/очистить` | Очистить контекст текущей сессии |
| `/context` | `/контекст` | Сформировать контекст перед началом работы |
| `/compact` | `/сжать` | Сжать длинную сессию с фокусированными инструкциями |
| `/loop <interval> <command>` | `/цикл <интервал> <команда>` | Запустить команду с периодическим выполнением |
